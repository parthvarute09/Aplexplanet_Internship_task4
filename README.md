# 🧪 Hypothesis Testing

## Business Question

**Does the new strategy result in a statistically significant improvement in sales?**

### Null Hypothesis (H₀)

> There is **no statistically significant difference in sales** after implementing the new strategy.

### Alternative Hypothesis (H₁)

> The new strategy results in a **statistically significant improvement in sales**.

---

## 📊 Statistical Test

An **Independent Samples T-Test** was used to compare sales between the two groups.

| Parameter              | Value                      |
| ---------------------- | -------------------------- |
| Test                   | Independent Samples T-Test |
| Confidence Level       | 95%                        |
| Significance Level (α) | 0.05                       |
| Metric                 | Sales                      |
| Null Hypothesis        | No significant difference  |
| Alternative Hypothesis | Significant improvement    |

# 💼 Business Insights

Based on the analysis and statistical validation, the key business insights are:

### 1. Sales Performance

The analysis evaluates whether the new strategy is associated with a meaningful change in sales performance.

### 2. Statistical Evidence

The hypothesis test provides statistical evidence to determine whether the observed difference in sales is likely to represent a genuine effect rather than random variation.

### 3. Business Impact

The statistical result can support management in deciding whether the strategy should be maintained, optimized, or reconsidered.

### 4. Data-Driven Decision Making

Combining descriptive analysis, visualization, and statistical testing provides stronger evidence for business decisions than relying on sales differences alone.
